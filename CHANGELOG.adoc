= Changelog

== 0.6.3 — 2026-09-10

* **Author chrome:** `{linked name} {circular avatar} via {product}` — name link first, avatar after, agent product plain (no parentheses, not linked).
* Circular clip: fixed square `.page-context-avatar-wrap` with `border-radius: 50%`, `overflow: hidden`, and `object-fit: cover` on the image.
* Vertical centering: `align-items: center` on `.page-context-author` / byline flex.
* Same credit shape in footer author cells; HTML meta still uses the plain human name.
* Legacy `{product} on behalf of {human}` and `{human} (via {product})` still parse.
* Schema version attribute `0.6.3`.

== 0.6.2 — 2026-09-10

* Lead-table label for `page-audience` is **Audience role** (not bare Audience) — role = permissions / access / usage expectations.
* Attribute name stays `page-audience` (Dublin Core `dcterms.audience` unchanged).
* Schema version attribute `0.6.2`.

== 0.6.1 — 2026-09-10

* **Lead nesting:** outer `.page-context-lead` is seamless (no border/wash); byline stays a child of that zone; inner `.page-context-panel` wraps only the key/value table.
* Soften panel wash/border; byline has no panel chrome (reads as normal doc chrome above the table panel).
* Tests assert byline is **not** inside `<table>` and lead table is wrapped by `.page-context-panel`.
* Schema version attribute `0.6.1`.

== 0.6.0 — 2026-09-10

* **Slim teaching lead:** byline `Last updated {date} by {avatar}{name}`; orientation/status stay in the lead table; authorship and classification move to the **footer**.
* Agent-assisted credits display as `{human} (via {product})` (parses legacy `{product} on behalf of {human}`).
* GitHub avatars via `https://github.com/{login}.png` (no OAuth); map via `page-*-github` or `page-context-authors`.
* **Keywords / Tags** render as muted underline links to filtered listing pages (`{base}/{slug}/`, default `/home/keywords/{slug}/`).
* Antora helper `@antora-supplemental/page-context/antora` generates keyword index pages (articles grouped by component).
* Schema version attribute `0.6.0`.

== 0.5.0 — 2026-09-10

* **Component home surface:** never render Audience / Usage context (attrs may still exist; HTML meta still emits).
* On that surface, authorship / dates / revision move to the **footer** (end of document).
* Detect via `:page-context-surface: component-home` (or `home`), or Antora `page-module=ROOT` + `page-relative-src-path=index.adoc`.
* Schema version attribute `0.5.0`.

== 0.4.0 — 2026-09-09

* Lead holds orientation **and** provenance: authorship, dates, doc version (house subset is one top panel).
* Footer is colophon-only: license/rights, locale, identifiers, see-also, contact.
* Schema version attribute `0.3.0`.

== 0.3.3 — 2026-09-09

* Keys left-aligned (`th` defaults to center in UA CSS) with `text-align: left !important`.
* More horizontal cell padding; footer aside gets larger top/bottom margin.
* Aside is the panel (border + wash + padding); table is borderless rows with thin dividers only.

== 0.3.2 — 2026-09-09

* Metadata table styling is fully independent of theme/doc table rules: no zebra/alternating row fills; thin outer border + thin inner cell dividers; muted type at in-doc TOC scale (`0.82em`); subtle surface wash in light and dark.
* High-specificity resets so Valentus/dark-mode `table tbody tr:nth-child(even)` (and similar) cannot restripe `.page-context-table`.

== 0.3.1 — 2026-09-09

* README: soft guidance — style `page-*` presentation in this package (point of interpretation), not via per-hub supplemental CSS forks.

== 0.3.0 — 2026-09-09

* Lead/footer markup is a compact key/value `<table class="page-context-table">` (not a heavy definition list).
* Default CSS: smaller muted type, thin ultra-light borders, transparent/light wash; dark-theme tokens via `html.dark-theme`.
* Does **not** own or wrap Asciidoctor/Antora in-doc TOC — TOC stays a separate block for the theme to style.

== 0.2.0 — 2026-08-25

* Expand `page-*` schema with common tokens from Dublin Core, Quarto/SSG front matter, AsciiDoc revision fields, Open Graph / citation meta, and Diátaxis/doc lifecycle.
* Emit HTML `<meta>` / `dcterms.*` / `og:*` / `article:*` when corresponding attributes are set.
* Aliases (`page-type` → `page-doc-type`, `page-creator` → `page-orig-author`, …).

== 0.1.0 — 2026-08-25

* Initial release: render `page-audience`, `page-usage-context`, `page-orig-author`, `page-last-author`, `page-last-edited` as lead + footer asides.
* Registry listing: root `antora-registry.md` + GitHub topics `antora-extension`, `antora`.
