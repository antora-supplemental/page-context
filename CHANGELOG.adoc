= Changelog

== 0.3.3 — 2026-09-09

* Keys left-aligned (`th` defaults to center in UA CSS) with `text-align: left !important`.
* More horizontal cell padding; footer aside gets larger top/bottom margin.
* Aside is the panel (border + wash + padding); table is borderless rows with thin dividers only.

== 0.3.2 — 2026-09-09

* Metadata table styling is fully independent of theme/doc table rules: no zebra/alternating row fills; thin outer border + thin inner cell dividers; muted type at in-doc TOC scale (`0.82em`); subtle surface wash in light and dark.
* High-specificity resets so Valentus/dark-mode `table tbody tr:nth-child(even)` (and similar) cannot restripe `.page-context-table`.

== 0.3.1 — 2026-09-09

* README: soft guidance — style `page-*` presentation in this package (point of interpretation), not via per-hub supplemental CSS forks.

== 0.3.0 — 2026-09-09

* Lead/footer markup is a compact key/value `<table class="page-context-table">` (not a heavy definition list).
* Default CSS: smaller muted type, thin ultra-light borders, transparent/light wash; dark-theme tokens via `html.dark-theme`.
* Does **not** own or wrap Asciidoctor/Antora in-doc TOC — TOC stays a separate block for the theme to style.

== 0.2.0 — 2026-08-25

* Expand `page-*` schema with common tokens from Dublin Core, Quarto/SSG front matter, AsciiDoc revision fields, Open Graph / citation meta, and Diátaxis/doc lifecycle.
* Emit HTML `<meta>` / `dcterms.*` / `og:*` / `article:*` when corresponding attributes are set.
* Aliases (`page-type` → `page-doc-type`, `page-creator` → `page-orig-author`, …).

== 0.1.0 — 2026-08-25

* Initial release: render `page-audience`, `page-usage-context`, `page-orig-author`, `page-last-author`, `page-last-edited` as lead + footer asides.
* Registry listing: root `antora-registry.md` + GitHub topics `antora-extension`, `antora`.
